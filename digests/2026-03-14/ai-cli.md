## 1. Панорама экосистемы

Экосистема AI CLI-инструментов вошла в фазу зрелой турбулентности: базовая функциональность реализована у всех ключевых игроков, однако надёжность и предсказуемость поведения остаются главным дефицитом. Кроссплатформенная совместимость — прежде всего Windows и ARM — стала системной болью сразу для пяти инструментов одновременно, что указывает на общую для рынка проблему приоритизации. Агентные возможности (multi-agent, subagents, watchdog) активно внедряются, но несут новый класс регрессий: молчаливые сбои, непрозрачность состояния, утечки контекста. Сообщества переходят от запросов фич к требованиям надёжности — это сигнал о том, что инструменты перешагнули порог ранних адоптеров и работают в реальных производственных окружениях.

## 4. Дифференциация

| Критерий | Claude Code | OpenAI Codex | Gemini CLI | Kimi Code | OpenCode | Qwen Code |
|---|---|---|---|---|---|---|
| **Фокус** | Плагин-экосистема, MCP-протокол | Агентный стек, Rust-ядро | Стабилизация Plan Mode, контекст | UX оболочки, медиа | Мультипровайдерность, TUI | Мультимодельность, хуки |
| **Целевая аудитория** | Enterprise + power users | Enterprise, DevOps | Широкая аудитория | macOS-разработчики | Polyglot-разработчики | ML/AI-инженеры |
| **Технический подход** | TypeScript + плагины через хуки | Rust-ядро + sandbox | TypeScript, ACP-протокол | Python | TypeScript + мультипровайдер | TypeScript + OpenAI-совместимый API |
| **Экосистемная открытость** | MCP-стандарт, высокая | Частично закрытая | ACP + VS Code | Ограниченная (запросы на открытие) | Высокая (кастомные провайдеры) | Высокая (OpenAI-compatible) |
| **Стадия** | Зрелый продукт | Pre-release, активный рефакторинг | Нightly, стабилизация | Стабильный, небольшая команда | Стабильный, активный рост | Ранняя зрелость |
| **Уникальная фича** | MCP Elicitation (v2.1.76) | Watchdog + Arena (Qwen-аналог) | Plan Mode | Medial-input (Cmd+V) | RAG-пайплайн | Мультимодельная Arena |

**Ключевые различия:**

- **Claude Code** строит платформу через MCP: сообщество закрывает пробелы быстрее, чем core-команда, что одновременно сила и риск (качество модерации PR).
- **OpenAI Codex** инвестирует в инфраструктурный рефакторинг (Rust, Dylint, named args) — выигрыш в долгосрочной сопровождаемости, но краткосрочная нестабильность.
- **Gemini CLI** имеет наибольшее число внешних контрибьюторов, однако Plan Mode — стратегическая фича — остаётся нестабильным, что создаёт разрыв между маркетингом и реальностью.
- **Kimi Code** — наиболее компактный проект с единственным core-контрибьютором (@RealKai42), что даёт согласованность кода, но создаёт bus factor риск.
- **OpenCode** — наиболее мультипровайдерный инструмент, что генерирует уникальный класс багов: каждый новый провайдер (Copilot, Bedrock, Grok) требует отдельных фиксов.
- **Qwen Code** агрессивно движется к плагинной архитектуре 0.13.0, при этом имеет P0-баги в базовом tool-call протоколе — характерное противоречие фазы быстрого роста.

## 6. Трендовые сигналы

### 🔴 Сигнал 1: Надёжность вытесняет функциональность как приоритет
Во всех шести инструментах топовые issues — не запросы на новые фичи, а требования исправить молчаливые сбои, неработающую аутентификацию, потерю контекста. **Вывод для разработчиков:** пользователи AI CLI перешли в production-стадию использования — они ожидают от инструментов того же качества надёжности, что от компиляторов и систем контроля версий.

---

### 🔴 Сигнал 2: MCP-стандарт становится де-факто протоколом
Claude Code строит вокруг него плагин-экосистему, Qwen Code реализует хуки по аналогичной модели, OpenCode развивает мультипровайдерность. Разработчикам инструментов, не поддерживающих MCP, предстоит объяснять пользователям, почему они выбрали иной путь.

---

### 🟠 Сигнал 3: Агентный стек генерирует принципиально новый класс ошибок
**Молчаливые сбои субагентов** (Claude Code #34251, Gemini CLI #21901, Codex watchdog PR) — это не обычные баги, а архитектурная проблема: агентные системы ломаются не с exception, а с правдоподобным, но неверным результатом. Потребуются новые паттерны: audit trails, heartbeat-механизмы, изоляция состояния.

- **SSE timeout при длинных операциях** (#17318) — агентные задачи с записью файлов прерываются, что делает ненадёжными длительные автоматизированные воркфлоу.

### 🟡 Провайдеры и конфигурация

- **OAuth-авторизация зависает** (#7992) — OpenAI авторизация не завершается на стороне OpenCode, несмотря на успех на стороне провайдера.
- **Бесконечные циклы при ошибках схем** (#17454) — отсутствие graceful degradation при несовместимости схем провайдера приводит к 100% CPU.
- **Bedrock + PDF attachments** (#17300) — некорректная расстановка `cachePoint` блокирует работу с документами.

### 🟢 UX и удобство

- **Numpad игнорируется в TUI** (#16100, #17457) — особенно болезненно для пользователей VS Code integrated terminal; исправление уже в PR #17459.
- **Vue LSP без диагностик** (#2756) — проблема существует с сентября 2025, PR готов (#4274), но не влит; раздражает Vue-сообщество.
- **Отсутствие real-time метрик токенов** (#17449) — пользователи не могут контролировать расходы в процессе генерации.
- **Низкий контраст в solarized теме** (#17448) — скроллбар практически невидим; мелочь, но сигнализирует о недостаточном QA визуальных компонентов.
